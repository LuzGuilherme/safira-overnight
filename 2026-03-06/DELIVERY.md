# 🚀 Launch Launchpad

**URL:** https://luzguilherme.github.io/safira-overnight/2026-03-06/

**Estilo:** Swiss Minimal 🏛️

---

## O que é

Uma checklist interactiva com **40+ directories e plataformas** onde publicar quando lançares um produto indie. Tracking de progresso local (no browser), filtros por prioridade, e links directos para submissão.

---

## Porquê isto?

Vi no Reddit esta semana uma thread sobre "list of directories to launch a startup" com 42 upvotes e 63 comentários. Claramente há procura por isto.

O problema: a maioria das listas são estáticas. Copias para um Notion, depois esqueces. Esta ferramenta resolve isso com:
- **Progress tracking** visual
- **Prioridades** (Essential → Recommended → Bonus)
- **Categorias** organizadas
- **Links directos** para cada submissão
- **Export JSON** do progresso

---

## Funcionalidades

### 📊 Dashboard
- Contagem de submissões (feitas vs total)
- Barra de progresso visual
- Stats em tempo real

### 🎯 Filtros
- **All** — todos os directories
- **Essential** — os 5 que TENS de fazer
- **Recommended** — alto ROI
- **Bonus** — para máxima cobertura
- **Pending** — ainda não feitos
- **Completed** — já submetidos

### 📁 Categorias
- Launch Platforms (Product Hunt, HN, Reddit)
- Directories (BetaList, Capterra, G2...)
- AI Directories (se aplicável)
- Social (Twitter, LinkedIn)
- Content (Dev.to, Medium, YouTube)
- Developer (GitHub, npm/PyPI)
- Community (Discord, Slack)
- SEO (Crunchbase, AngelList)
- Media (Newsletters)

### 💾 Persistência
- Progresso guardado no localStorage
- Export para JSON
- Reset se necessário

---

## Stack

- HTML + CSS + Vanilla JS
- Zero dependências
- ~27KB total
- Funciona offline (depois de carregar)

---

## Escolha do Estilo

**Swiss Minimal** porque:
1. É uma ferramenta de trabalho — precisa de ser funcional
2. Lista com muitos items — hierarquia visual clara é essencial
3. Foco na informação, não na decoração
4. Preto e branco força o foco no que importa
