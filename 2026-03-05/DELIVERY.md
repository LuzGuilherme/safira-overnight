## 📋 O que é?

Uma calculadora visual e interactiva para indie hackers e fundadores de micro-SaaS calcularem:
- Quanto precisam de cobrar
- Quantos clientes precisam para atingir goals ($1K, $5K, $10K MRR)
- Simulação de crescimento a 12 meses
- Métricas críticas (LTV, CAC, payback, churn)
- Insights automáticos baseados nos dados

---

## 🎯 Porquê isto?

### Pesquisa
Encontrei um artigo trending no Medium ("50 Profitable Micro-SaaS Ideas I'm Watching in 2026") que fala sobre o "48-Hour MVP Playbook" e a importância de calcular unit economics antes de construir.

O padrão que vi: muitos indie hackers não sabem quantos clientes precisam para viver do produto. A pergunta "$5K MRR" aparece constantemente em r/indiehackers e Twitter/X.

### Problema
Calcular estas métricas manualmente é chato e propenso a erros. Especialmente:
- LTV vs CAC
- Impacto do churn no crescimento
- Tempo real para atingir milestones

### Solução
Uma ferramenta visual, rápida, e visualmente memorável que resolve isto em segundos.

---

## 🎨 Estilo: Retro Tech ⚡

**Justificação:**
- Target audience: indie hackers, developers, tech founders
- Retro/synthwave aesthetic é nostálgica mas diferente — memorable
- Tons néon (cyan, pink, purple) comunicam "tech" sem ser genérico
- Grid background + scanlines = terminal vibes
- Diferente dos últimos builds (Bold Maximalist, Newspaper)

**Elementos usados:**
- Background escuro (#0a0a1a)
- Cores neon com glow effects
- Font "Press Start 2P" para headlines (pixel aesthetic)
- "Space Mono" para body (monospace = code vibes)
- Grid lines + scanlines CRT
- Animação de flicker no logo

## ✨ Features

### 1. Pricing Configuration
- 3 modelos: MRR, Usage-based, One-time
- Inputs: preço, churn, novos clientes/mês, CAC
- Cálculos automáticos: LTV, LTV:CAC ratio, payback period, break-even

### 2. MRR Goals Calculator
- Visual para $1K, $5K, $10K milestones
- Quantos clientes precisas para cada
- Progress bar para $5K
- Input de clientes actuais

### 3. 12-Month Growth Simulator
- Timeline visual com projeção de MRR
- Considera churn no cálculo
- Month 6, Month 12, e total revenue anual

### 4. Industry Benchmarks
- Median micro-SaaS MRR
- Target LTV:CAC ratio
- Average churn rates
- Median pricing ranges
- Time to $5K MRR

### 5. Quick Insights
- Análise automática dos números
- Alertas de pricing (muito baixo/alto)
- Alertas de churn
- Sugestões baseadas em benchmarks
