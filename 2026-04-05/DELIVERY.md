# 🌙 Overnight Build — 2026-04-05

## Projecto
**Signal Scout — Trend to Tool Validator**

URL: https://luzguilherme.github.io/safira-overnight/2026-04-05/

## O que é
Uma ferramenta standalone para transformar sinais de comunidades (Reddit, Hacker News, Product Hunt) em decisões accionáveis de build.

Permite:
- Registar sinais com métricas (upvotes, comentários, build time, saturação)
- Calcular **Opportunity Score (0-100)**
- Ver ranking automático das top 3 oportunidades
- Gerar recomendação imediata de próxima acção

## Porque este projecto
### Pesquisa desta noite
- **Reddit/indiehackers:** forte conversa sobre founders perdidos entre ideias e saturação de AI wrappers
- **Hacker News Show:** sinais claros em ferramentas para agentes (ex: controlo de token budget), utilitários práticos e produtos “boring but useful”
- **Product Hunt:** continuidade de lançamentos em produtividade + AI workflow compression

### Insight
O problema não é só “ter ideias”; é **priorizar rapidamente** com critérios consistentes.

## Estilo escolhido
**Newspaper / Editorial Classic 📰**

### Justificação
- O produto é informativo e de decisão (credibilidade + hierarquia textual)
- Forte fit com conteúdo denso e comparação de sinais
- Diferente dos últimos estilos usados (Retro Tech, Editorial Clean, Neo Brutalist)

Referências conceptuais: NYTimes / FT-style layout editorial.

## Stack
- HTML + CSS + JS vanilla
- Sem dependências
- 100% client-side

## Testes realizados
- Adição de novo sinal manual
- Ordenação por score (descendente)
- Remoção de item
- Limpar estado
- Reset para dados demo
- Recomendação dinâmica por faixa de score

## Resultado
Build curto, útil e alinhado com o objetivo de gerar side-projects mais rapidamente com base em sinais reais de mercado.
