# 📓 The Decision Journal

**Data:** 2026-03-19  
**Categoria:** Produtividade/Founder Tools  
**Estilo:** Editorial Clean ☀️

---

## 🎯 O Que É

Um diário digital para founders documentarem e aprenderem com as suas decisões. Baseado na prática de que os melhores fundadores aprendem sistematicamente com escolhas passadas.

**URL:** https://luzguilherme.github.io/safira-overnight/2026-03-19/

---

## 💡 Porquê Isto?

### O Problema
Founders tomam centenas de decisões por mês. A maioria esquece o raciocínio por trás delas. Quando algo corre mal (ou bem), não têm contexto para aprender.

### A Solução
Uma ferramenta simples para:
1. **Documentar decisões** no momento (contexto, opções, raciocínio)
2. **Agendar reviews** para o futuro
3. **Comparar expectativa vs realidade**
4. **Identificar padrões** na qualidade das decisões

### Inspiração
- Diário de investimentos (prática comum entre traders)
- "Thinking, Fast and Slow" de Kahneman
- Conceito de "decision review" do Ray Dalio

---

## ✨ Features

### Core
- ✅ Formulário estruturado para registar decisões
- ✅ Campos: título, categoria, contexto, opções, escolha, raciocínio, outcome esperado
- ✅ Nível de confiança (alto/médio/baixo)
- ✅ Data de review agendável

### Review System
- ✅ Tab de "Pending Review" mostra decisões prontas para avaliar
- ✅ Modal de review: o que aconteceu, rating, lições aprendidas
- ✅ Status visual (Success/Mixed/Failed)

### Insights
- ✅ Taxa de sucesso global
- ✅ Precisão por nível de confiança (interessante ver se "high confidence" acerta mais)
- ✅ Breakdown por categoria

### UX
- ✅ Design Editorial Clean (serif elegante, muito whitespace)
- ✅ Export/Import JSON
- ✅ LocalStorage (dados ficam no browser)
- ✅ Exemplos de demonstração incluídos

## 🎨 Justificação do Estilo

**Editorial Clean** foi escolhido porque:
1. É uma ferramenta de reflexão — precisa de calma visual
2. Conteúdo denso (texto, não dados) — tipografia serif melhora leitura
3. Target é founders pensativos — não dev tools rápidos
4. Último uso foi 2026-03-09 (10 dias) — diversidade de estilos

**Referências usadas:**
- Medium (article layout)
- Notion About page (whitespace)
- Stripe Press (tipografia)

## 💭 Reflexão

Esta ferramenta resolve um problema real que muitos founders têm mas não reconhecem: a amnésia decisional. Quando algo falha, não lembram porque escolheram aquele caminho. Quando algo funciona, não sabem replicar.

O valor está em:
1. **Forçar clareza** — escrever o raciocínio obriga a pensar
2. **Criar accountability** — review agendado não deixa escapar
3. **Gerar padrões** — com tempo, revela tendências (ex: "overconfident em hiring")

Pode evoluir para:
- Versão com backend (partilhar entre co-founders)
- Integração com calendário (reminder de review)
- AI analysis dos padrões de decisão
