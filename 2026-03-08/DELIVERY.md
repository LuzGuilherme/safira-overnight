# 🥗 Athlete Fuel Planner

> *Uma calculadora de nutrição para atletas de endurance*

**Data:** 2026-03-08
**Estilo:** Organic Soft 🌿

## 🎯 O Que É

Uma ferramenta elegante que calcula as necessidades nutricionais diárias para atletas de endurance (triathlon, Ironman, maratona) e gera planos de refeições simples.

## 🧠 Porquê Isto?

**Contexto:**
- Guilherme está em preparação para Ironman (Outubro 2026)
- Treina 10-15h/semana com intensidade variável
- Nutrição é crítica para performance E recuperação
- Ferramentas existentes são ou muito complexas ou genéricas demais

**Raciocínio:**
1. ⚖️ **Trade-off:** Calculadora simples vs app completa → Escolhi simples porque pode usar HOJE
2. 🎨 **Estilo Organic Soft:** Primeira vez usado em contexto fitness — reforça que nutrição é wellness, não só números
3. 📊 **Categoria nova:** Nutrição/Meal Planning estava vazia no portfolio overnight

## ✨ Funcionalidades

### Inputs
- **Volume de treino:** Horas semanais, split swim/bike/run
- **Fase de treino:** Base, Build, Peak, Recovery
- **Dados físicos:** Peso, altura, idade, género
- **Ajustes:** Intensidade média, objectivos (manter, perder, ganhar)

### Outputs
- **Calorias diárias:** BMR + factor de actividade dinâmico
- **Macros:** Carbs/Proteína/Gordura com split ajustável
- **Timing nutricional:** Pré/Durante/Pós treino
- **Hidratação:** Targets baseados em volume
- **Plano de refeições:** Sugestões para cada refeição
- **Exportar:** Copiar plano como texto

### UX
- Responsive (mobile-first)
- Dados guardados em LocalStorage
- Zero dependências externas
- Cálculos instantâneos
