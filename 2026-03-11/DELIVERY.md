# 🔥 Build Streak Dashboard

**Overnight Build #40** · 11 Março 2026

---

## O que é?

Um dashboard que visualiza toda a jornada de overnight builds — 36 noites consecutivas de criação! Estilo contribution graph do GitHub, mas para celebrar e acompanhar o progresso dos builds.

---

## Funcionalidades

### 📊 Contribution Graph
- Visualização estilo GitHub dos últimos 84 dias
- Tooltips com nome e emoji de cada build
- Verde vibrante para builds realizados

### 📈 Stats Rápidos
- Total de builds
- Categorias exploradas (14)
- Estilos utilizados (10)
- Data de início (28 Jan)
- Média semanal

### 📁 Breakdown por Categoria
- Bar chart horizontal
- Ordenado por frequência
- Top 8 categorias

### 🎨 Breakdown por Estilo
- Visualização da diversidade estética
- Tracking de estilos mais/menos usados

### 📜 Timeline Interactiva
- Lista cronológica de todos os builds
- Filtros: Todos, Última Semana, SaaS, Marketing, Pessoal
- Emoji, categoria e estilo em cada entrada

---

- **HTML/CSS/JS** puro (zero dependências)

---

## Porquê este projecto?

1. **Celebração** — 36 noites é um feito impressionante que merece ser visualizado
2. **Meta-reflexão** — Um build sobre os builds, para ver padrões e evolução
3. **Motivação** — Ver o progresso visual ajuda a manter momentum
4. **Referência** — Dashboard útil para consultar o histórico rapidamente

---

## Estilo: Data Dense 📊

**Justificação:**
- Dashboard de analytics pede estilo focado em dados
- Não usado desde 02-25 (14 dias) — boa rotação
- Fundo escuro #0d1117 (GitHub-style)
- Tipografia monospace para dados
- Verde como accent (GitHub contribution green)
- Densidade de informação alta mas organizada

**Referências:**
- GitHub contribution graph
- Grafana dashboards
- Linear app
